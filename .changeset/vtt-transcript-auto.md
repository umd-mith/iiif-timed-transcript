`IIIFPlayer.Root` gains `annotations="auto"`: transcript annotations are built from the manifest — embedded `TextualBody` annotations (motivation `supplementing`, `commenting`, or `tagging`) first, else — only when those yield nothing — the canvas's external WebVTT `supplementing` track, fetched on demand with `media-captions` (now a runtime dependency). New `onError(error, { fatal, source })` prop; `transcriptStatus` on the player context, `PlayerRef`, and the children snippet. `getSupplementaryVTTTracks` now finds VTT tracks inside `Choice` bodies and de-duplicates by `src`; `ExternalResourceSchema` keeps `label`/`language` (tolerantly). Behaviour changes: a captioned video whose transcript panel is populated no longer starts with captions showing — every attached track is set to `hidden` once per canvas and never written again, so hiding the transcript panel later does not bring the captions back (pass `tracks` explicitly to opt out); the tracks stay available in native controls; a missing `hls.js`/`dashjs` now surfaces as a player error instead of a console warning.
