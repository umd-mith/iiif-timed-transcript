New `<iiif-transcript-player>` custom element for pages without a Svelte build: `@umd-mith/svelte-iiif-transcript-player/element` (ESM, `register()`) or the built IIFE file (`dist/element/iiif-transcript-player.iife.js`, hls.js bundled — a classic script that installs `window.IIIFTranscriptPlayer`, not a module; vendor it directly — it is not resolvable through the package's `exports` map). Attributes `manifest-url`, `canvas-index` (reflected), `initial-time`, `autoplay`; properties `annotations`, `preprocessManifest`, `errorCallback`, `playerRef`; events `iiif-player-ready`, `iiif-player-error` (`{ error, fatal, source }`), `iiif-player-canvas-change`; custom-property theming.

Host inputs are validated and reported as non-fatal `source: "host"` errors instead of failing silently: a `canvas-index` that is not a non-negative integer (`"abc"`) falls back to `0`, an out-of-range index is ignored, an `initial-time` that is not a non-negative finite number is ignored, and connecting with no `manifest-url` is reported. Removing `canvas-index` is not an error — it means the default, canvas `0`. Clearing `manifest-url` unmounts the player and resets `playerRef` to `null`. Re-connecting a detached element rebuilds the player and fires `iiif-player-ready` again; `initial-time` is applied only on the first connection, so a tab or accordion that re-parents the element no longer rewinds playback.

Core changes: `getPrimaryResource` resolves `Choice` bodies (first Sound/Video; `[Choice{Video}, Image]` now resolves to the video); `IIIFPlayer.Root` gains `preprocessManifest` (bypasses the manifest cache when set) and ignores a non-integer `switchCanvas` index; IIIF Auth API 1 service references (`@type`/`@id`) are tolerated instead of rejecting the whole manifest — `service[].type` is therefore optional, so its inferred type is `string | undefined`.
