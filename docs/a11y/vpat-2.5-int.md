## Scope note

**This report claims WCAG 2.1 Level AA exactly, and does not claim WCAG
2.2.** The DOJ Title II rule (28 CFR 35.200) names WCAG 2.1 AA for UMD's
compliance cohort. Claiming 2.2 would add nine criteria this component has
not been evaluated against, including 2.5.8 Target Size (Minimum), which the
search previous/next buttons would likely fail at their current padding.
Volunteering a standard and then failing a criterion under it is worse than
not volunteering it. Note that 2.1 still carries 4.1.1 Parsing, which 2.2
removes; it is scored below.

**Component, not page.** WCAG conformance is defined for a full page. This
report describes `<iiif-transcript-player>` evaluated in isolation on a
minimal host page. Any page embedding it depends further on the host page
and on the IIIF manifest content that page supplies. Three categories of
criteria are marked accordingly:

1. **Host-page criteria** the component cannot satisfy on its own — page
   language, bypass blocks, page title, consistent navigation and
   identification across pages — marked **Not Applicable**. The embedding
   page owns them.
2. **Content-dependent criteria**, the 1.2.x block. See the Content
   Responsibility note above that block.
3. **Theming-dependent criteria**, 1.4.3 and 1.4.11. Those claims hold for
   the shipped default `--iiif-player-*` values only. See "Theming
   responsibility" in `README.md`.

## Content Responsibility note (applies to the whole 1.2.x block)

The component renders whatever caption tracks and transcript annotations the
supplied IIIF manifest carries. It neither generates nor validates captions,
transcripts, or audio descriptions. **Conformance with 1.2.1 through 1.2.5
for any given embedded item depends on the manifest publisher's content**,
not on this component. Where a row below reflects a gap in the _component's
own behavior_ rather than in manifest content, the Remarks say so and
distinguish the two.

The component does one piece of good citizenship here: a development-time
console warning, numbered by success criterion, when a video canvas has no
caption tracks at all (`src/lib/player/Viewer.svelte` — "[IIIFPlayer] Video
has no caption tracks… for WCAG 1.2.2 compliance."). Cited as a mitigation,
not as a substitute for any row's conformance level.
